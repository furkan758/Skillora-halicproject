# Skillora — Haliç Project

- `data ui/`: React, TypeScript ve Vite ile geliştirilen arayüz.
- `data backend/`: Backend dosyaları için ayrılan klasör. `.gitkeep`, boş klasörün GitHub'da görünmesini sağlar; backend kodu eklendiğinde kaldırılabilir.

## Arayüzü çalıştırma

```sh
cd "data ui"
npm install
npm run dev
```

Arayüzün ayrıntılı açıklaması ve diğer komutlar için [UI README](data%20ui/README.md) dosyasına bakın.
